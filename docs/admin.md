# Админка

URL: `http://<хост>:4000/admin`  
Вход — пароль (cookie `mikrollm_session`, 12 часов, HttpOnly). После пяти неверных попыток с одного IP пауза 10 минут.

Меню: **Статус · Модели · Ключи · Чат · Лог**.

## Статус

Карточки серверов Ollama: онлайн/офлайн, задержка, модели на диске, что сейчас в RAM.

- **Добавить Ollama** — имя и базовый URL (`http://192.168.88.82:11434`, без хвоста `/`).
- **Обновить статусы** — внеочередной опрос `/api/version`, `/api/tags`, `/api/ps`.
- Смена пароля админки — внизу страницы (минимум 6 символов).

Health-check сам повторяется каждые 10 секунд.

## Модели

Один список с дисков всех Ollama.

1. Отметьте модели → **В шлюз** — появится alias с тем же именем, что у Ollama, и выбранной политикой LB.
2. **RAM**: `82 · в RAM` загружает веса (`keep_alive: -1`), `выгрузить` снимает (`keep_alive: 0`). Большая модель может грузиться несколько минут.
3. **Диск**: `✕` удаляет файл с выбранного хоста (не alias).
4. Блок **Скачать модель в Ollama** — `pull`. Полоса прогресса **не сбрасывается** при обновлении страницы: задача идёт на шлюзе и пишется в SQLite. После рестарта контейнера незавершённый pull подхватывается снова.
5. **Свой alias** — другое имя для клиентов (например `fast` → `qwen3.8:27b-mlx`).

Политики балансировки:

| Политика | Поведение |
|---|---|
| `least_conn` | меньше активных запросов (по умолчанию) |
| `round_robin` | по кругу |
| `failover` | первый живой из списка |

Убрать alias из шлюза ≠ удалить файл в Ollama.

## Ключи

Клиенты ходят с `Authorization: Bearer sk-…`.

- Имя, RPM (`0` = без лимита), список моделей или «Все модели».
- Секрет показывается **один раз** — сразу копируйте.
- В таблице: prefix, пилюли доступа, счётчик запросов, время последнего вызова, отзыв.

Пустой allowlist и `*` означают все модели. Иначе сверяется alias, который клиент передал в `model`.

## Чат (playground)

Как LiteLLM Playground: выбрать alias или имя Ollama, писать в формате чата.

- Запросы идут через тот же шлюз (`/v1/chat/completions`), API-ключ не нужен — только сессия админки.
- Стрим токенов, Stop, новый чат, temperature, max_tokens.
- Enter — отправить, Shift+Enter — новая строка.
- У thinking-моделей блок рассуждения показывается отдельно.

Если модель не в RAM, первый ответ может занять минуту (Ollama поднимает веса).

## Лог

Последние запросы API: ключ (prefix), модель, бэкенд, статус, задержка, байты. Хранится до 500 записей, ротация автоматически.

Запросы из админского чата пишутся с prefix `admin` и не крутят счётчик ключей.
